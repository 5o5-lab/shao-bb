这是一个专为中文大语言模型及 Agent 设计的省流 (Token-saving) 技能（Skill）。基于海外原版 [Caveman](https://github.com/JuliusBrussee/caveman) 的核心理念二次重构，不仅削减了高达 75% 的无效 Token 与废话，同时还能保留完整准确的技术见解与代码逻辑。**核心理念：旨在简化不必要的输出，而绝不减少传达的语义点，确保读者获取的信息量百分百无损。**

## 为什么需要 Shao-bb？

看看我们在日常对话中浪费了多少 Token 和生命：

### 🗣️ 普通模式（消耗 60+ Tokens，含大量情绪糖精）

> “好的，我知道你现在的情况了！关于你在 React 中遇到的无限重渲染的问题，主要是因为你在进行属性传递的时候每次都传入了一个全新的内联对象，React 的浅层比较机制会认为其是一个新的引用。所以我建议你使用 useMemo 把它包裹起来哦！”

### 🪨 Shao-bb Ultra 模式（消耗 15 Tokens，刀刀见血）

> “内联对象作 prop。每次渲染生成新引用 -> 触发重渲染。用 `useMemo`。”

**技术精度：100% | 速度：+300% | 废话：0%**

## 三大挡位 (Levels)

| 模式 | 指令 | 效果演示 |
|---|---|---|
| **Lite (微省流)** | `/shao-bb lite` | “React 重渲染因为内联对象导致了新的引用。用 `useMemo` 包裹住该对象即可。” |
| **Ultra (电报体)** | `/shao-bb ultra` | “内联对象 -> 新引用 -> 触发重渲染。使用 `useMemo` 包裹（注：确保语义完整）。” |

## 安装与使用

在本地 `skills` 目录下直接放置本文件夹后，可全局或针对项目使用。

- **显式激活**：对话时开头加入 `/shao-bb ultra` 或“电报模式”。
- **恢复原状**：输入“停止省流”或“退出电报体”。

### 何时它会自动恢复正常说话？
当系统判定你即将执行**高危操作**（例如删除核心库、覆盖数据库等）时，Shao-bb 骨子里的安全基因会让它瞬间切回啰嗦的“家长模式”，反复跟你确认。

> *“高危鉴别。暂停省流。请确认是否要覆盖主库表结构...”*
